
# AGENTS.md

- **Shell:** zsh
- **Prefix:** Always prefix commands with `rtk` (e.g., `rtk git status`). Use `rtk proxy <cmd>` for raw execution.

## Required Modern Tools

| Use | Instead of / For |
|---|---|
| `rg` | `grep -r` |
| `fd` | `find` |
| `fzf` | fuzzy filter |
| `bat` | `cat` |
| `eza` | `ls` |
| `sd` | `sed` |
| `fastmod` | Multi-file find & replace |
| `jq` / `yq` | JSON / YAML/TOML/XML processing |
| `xh` | `curl` |
| `hurl` | Scripted HTTP / API tests |
| `sg` (`ast-grep`) | AST-based search & rewrite |
| `ruff` | Python lint & format |
| `oxlint` / `oxfmt`| JS/TS lint & format |
| `uv` | `python`, `pip`, `venv`, `poetry` |
| `bun` | `node`, `npm`, `npx`, `yarn` |
| `tokei` | Code line counts |
| `playwright` | Browser automation / e2e |
| `parallel` | Concurrent shell execution |
