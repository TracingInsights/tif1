`tif1` provides Jupyter notebook integration with rich HTML displays, automatic environment detection, and interactive utilities for Formula 1 data analysis. The library shows formatted displays for Session, Driver, and Lap objects in the notebook.

## Overview

The Jupyter integration module (`tif1.jupyter`) provides:

- **Automatic Environment Detection**: Detects when running in Jupyter and enables rich displays on import of `tif1.jupyter`
- **Rich HTML Representations**: Formatted displays for `Session`, `Driver`, and `Lap` objects
- **DataFrame Summaries**: `display_dataframe_summary()` returns an HTML line with shape and memory usage
- **One Import**: `import tif1.jupyter` in a notebook is the only setup step
- **Fallback Support**: Outside a Jupyter kernel, no class is patched and objects keep their standard `repr()`

<Note>
The examples on this page run inside an IPython kernel. `IPython`, `ipywidgets`, and `psutil` are not `tif1` dependencies. Install them in the notebook environment with `pip install ipython ipywidgets psutil`.
</Note>

---

## Automatic Activation

The Jupyter integration activates automatically when `tif1.jupyter` is imported in a Jupyter environment. A plain `import tif1` does not import this module. Detection targets IPython kernels, such as the kernels that Jupyter Notebook and JupyterLab start.

### How It Works

When `tif1.jupyter` is imported, the module:

1. **Detects the Environment**: Checks if IPython is available and if an IPython kernel is running
2. **Enables Rich Displays**: Patches the Session, Driver, and Lap classes with `_repr_html_()` methods
3. **Logs Activation**: Logs `Jupyter display enabled` at `INFO` level to the `tif1.jupyter` logger
4. **Handles Errors**: Logs a warning and leaves the classes unchanged when the patch fails

```python
import tif1
import tif1.jupyter  # Enables rich displays when a Jupyter kernel is running

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
session  # Displays the rich HTML representation
```

### Environment Detection Details

The `_is_notebook()` function performs the following checks:

- Tries to import the `IPython` module
- Retrieves the current IPython instance via `get_ipython()`
- Checks for `IPKernelApp` in the shell configuration (indicates Jupyter kernel)
- Returns `True` only if all checks pass, which confirms a running IPython kernel

A terminal IPython session is not a kernel, so `_is_notebook()` returns `False` there.

## Rich HTML Displays

After `import tif1.jupyter` in a kernel, `Session`, `Driver`, and `Lap` objects display as HTML in a cell. These displays are styled with borders, colors, and structured tables.

### Session Display

The Session object displays information about the loaded F1 session: year, Grand Prix name, session type, backend, and driver count.

**Display Features:**
- 🏎️ Emoji icon for quick visual identification
- Bordered container with light gray background
- Structured table layout with key-value pairs
- URL-decoded Grand Prix and session names (handles special characters)
- Driver count once the driver list or the laps are in memory. Until then, the row shows "Not loaded". Rendering the card never starts a download
- Backend library indicator (pandas or polars)

```python
import tif1

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
session.load(telemetry=False)
session
```

### DataFrame Summary Display

`display_dataframe_summary(df)` returns a one-line HTML summary for a pandas or polars DataFrame. `tif1` does not attach this summary to DataFrames automatically.

**Display Features:**
- Green left border for visual emphasis
- Row count with thousands separator
- Column count
- Memory usage in MB (calculated differently for pandas vs polars)
- Compact single-line format

```python
from IPython.display import HTML, display
from tif1.jupyter import display_dataframe_summary

laps = session.laps
display(HTML(display_dataframe_summary(laps)))  # Summary line
laps  # Standard DataFrame display
```

**HTML Output Structure:**
```html
<div style="border-left: 3px solid #4CAF50; padding-left: 10px; margin: 10px 0;">
    <strong>DataFrame Summary:</strong> 1,234 rows × 25 columns | Memory: 2.45 MB
</div>
```

**Memory Calculation:**
- **Pandas**: Uses `df.memory_usage(deep=True).sum()` for accurate memory including object dtypes
- **Polars**: Uses `df.estimated_size()` if available, otherwise returns 0

## Manual Control and Advanced Usage

The Jupyter integration activates when `tif1.jupyter` is imported. Control and customize the display behavior manually for advanced use cases.

### Manual Activation

Manually enable Jupyter displays with the `enable_jupyter_display()` function when needed (for example, to restore the displays after [removing them](#disabling-rich-displays)):

```python
from tif1.jupyter import enable_jupyter_display

# Manually enable rich displays
enable_jupyter_display()
```

**What This Does:**
- Returns without changes when `_is_notebook()` is `False`
- Imports Session, Driver, and Lap classes from `tif1.core`
- Patches each class with a `_repr_html_()` method
- Logs activation status to the logger
- Logs a warning instead of raising if the classes cannot be imported or patched

**When to Use:**
- Restore the displays after removing the `_repr_html_()` methods
- Repeat the patch after the logger reported a failure

### Environment Detection

Check if the code runs in a Jupyter environment:

```python
from tif1.jupyter import _is_notebook

if _is_notebook():
    print("Running in Jupyter - rich displays enabled")
else:
    print("Not in Jupyter - using standard text output")
```

**Use Cases:**
- Conditional display logic
- Notebook vs script detection
- Custom display implementations
- Testing different output formats

**Note**: The leading underscore marks `_is_notebook` as a private helper. It is not part of the public API.

### Programmatic HTML Generation

Generate the HTML strings programmatically, then display or save them:

```python
import tif1
from IPython.display import HTML, display
from tif1.jupyter import display_session_info, display_driver_info, display_lap_info

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")

# Generate HTML string
html_output = display_session_info(session)

# Use in custom displays
display(HTML(html_output))

# Save to file
with open("session_info.html", "w") as f:
    f.write(html_output)

# Combine multiple displays
driver = session.get_driver("VER")
combined_html = f"""
<div>
    {display_session_info(session)}
    <br>
    {display_driver_info(driver)}
</div>
"""
display(HTML(combined_html))
```

### Custom Display Functions

Create custom display functions for specific use cases:

```python
from tif1.jupyter import display_session_info
from IPython.display import HTML, display
import tif1

def display_session_with_fastest_lap(session):
    """Custom display showing session info + fastest lap."""
    fastest = session.get_fastest_laps(by_driver=False).iloc[0]

    session_html = display_session_info(session)
    fastest_html = f"""
    <div style="border: 1px solid #4CAF50; padding: 10px; margin-top: 10px; border-radius: 5px;">
        <h4>⚡ Fastest Lap</h4>
        <p><strong>Driver:</strong> {fastest['Driver']}</p>
        <p><strong>Time:</strong> {fastest['LapTimeSeconds']:.3f}s</p>
        <p><strong>Lap:</strong> {int(fastest['LapNumber'])}</p>
    </div>
    """

    display(HTML(session_html + fastest_html))

# Usage
session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
display_session_with_fastest_lap(session)
```

### Disabling Rich Displays

Use standard text output in Jupyter when preferred:

```python
# Remove _repr_html_ methods
from tif1.core import Session, Driver, Lap

if hasattr(Session, '_repr_html_'):
    delattr(Session, '_repr_html_')
if hasattr(Driver, '_repr_html_'):
    delattr(Driver, '_repr_html_')
if hasattr(Lap, '_repr_html_'):
    delattr(Lap, '_repr_html_')

# Now objects will use standard repr()
session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
session  # Shows text representation
```

## Notebook Best Practices and Patterns

### 1. Efficient Data Loading

Load session data efficiently by controlling what gets fetched:

```python
import tif1

# Basic session creation (no data loaded yet)
session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")

# Load only what you need
session.load(laps=True, telemetry=False, messages=False, weather=False)

# Access loaded data
laps = session.laps
print(f"Loaded {len(laps)} laps")

# Load additional data on demand: the attribute fetches it on first access.
# Do not call session.load(weather=True) here: load() defaults to
# laps=True and telemetry=True, so that call fetches all telemetry too.
weather = session.weather
```

**Performance Tips:**
- Use `session.load()` with specific parameters to avoid fetching unnecessary data
- Every `load()` flag defaults to `True`, so pass `telemetry=False` unless all telemetry is needed
- Telemetry data is large - only load when needed
- Weather and race control messages are small tables compared to telemetry
- The cache (enabled by default) serves repeated loads

### 2. Progress Indication

Provide visual feedback during long-running operations:

```python
from IPython.display import display, HTML, clear_output
import tif1

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")

# Show loading message
display(HTML("<p>⏳ Loading session data...</p>"))

# Load data (skip the bulk telemetry fetch)
session.load(telemetry=False)
laps = session.laps

# Update with success message
clear_output(wait=True)
display(HTML(f"<p>✅ Loaded {len(laps)} laps from {len(session.drivers)} drivers</p>"))

# Display session
session
```

**Advanced Progress Tracking:**

```python
from IPython.display import display, HTML, clear_output
import tif1

def load_session_with_progress(year, gp, session_type):
    """Load session with detailed progress updates."""
    display(HTML("<div id='progress'>⏳ Creating session...</div>"))
    session = tif1.get_session(year, gp, session_type)

    clear_output(wait=True)
    display(HTML("<div id='progress'>⏳ Loading laps...</div>"))
    session.load(laps=True, telemetry=False, weather=False, messages=False)

    clear_output(wait=True)
    display(HTML("<div id='progress'>⏳ Loading weather...</div>"))
    session.load(laps=False, telemetry=False, weather=True, messages=False)

    clear_output(wait=True)
    display(HTML(f"<div id='progress'>✅ Complete! Loaded {len(session.laps)} laps</div>"))

    return session

session = load_session_with_progress(2025, "Bahrain Grand Prix", "Race")
```

### 5. Interactive Widgets

Use `ipywidgets` for interactive data exploration:

```python
import tif1
import ipywidgets as widgets
from IPython.display import display, HTML

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
session.load(telemetry=False)

# Display session
session

# Get driver codes
drivers_df = session.drivers_df
driver_codes = sorted(drivers_df["Driver"].tolist())

# Create interactive driver selector
driver_dropdown = widgets.Dropdown(
    options=driver_codes,
    description='Driver:',
    style={'description_width': '80px'}
)

# Create output widget
output = widgets.Output()

def on_driver_change(change):
    """Update display when driver selection changes."""
    with output:
        output.clear_output()

        driver_code = change['new']
        driver = session.get_driver(driver_code)

        # Display driver info
        display(driver)

        # Get and display statistics
        driver_laps = driver.laps
        fastest = driver.get_fastest_lap()

        if not fastest.empty:
            stats_html = f"""
            <div style="border: 1px solid #ddd; padding: 10px; margin-top: 10px; border-radius: 5px;">
                <h4>📊 Statistics</h4>
                <table style="width: 100%;">
                    <tr><td><strong>Total Laps:</strong></td><td>{len(driver_laps)}</td></tr>
                    <tr><td><strong>Fastest Lap:</strong></td><td>{fastest['LapTimeSeconds'].iloc[0]:.3f}s</td></tr>
                    <tr><td><strong>Fastest Lap Number:</strong></td><td>{int(fastest['LapNumber'].iloc[0])}</td></tr>
                    <tr><td><strong>Compound:</strong></td><td>{fastest['Compound'].iloc[0]}</td></tr>
                    <tr><td><strong>Average Lap Time:</strong></td><td>{driver_laps['LapTimeSeconds'].mean():.3f}s</td></tr>
                </table>
            </div>
            """
            display(HTML(stats_html))

# Attach event handler
driver_dropdown.observe(on_driver_change, names='value')

# Display widgets
display(HTML("<h3>🔍 Interactive Driver Explorer</h3>"))
display(driver_dropdown, output)

# Trigger initial display
on_driver_change({'new': driver_codes[0]})
```

**Advanced Widget Example with Multiple Controls:**

```python
import tif1
import ipywidgets as widgets
from IPython.display import display, HTML
import matplotlib.pyplot as plt
from tif1.plotting import setup_mpl, get_driver_color_mapping

setup_mpl()

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
session.load(telemetry=False)

# Create controls
drivers_df = session.drivers_df
driver_codes = sorted(drivers_df["Driver"].tolist())

driver_selector = widgets.SelectMultiple(
    options=driver_codes,
    value=[driver_codes[0]],
    description='Drivers:',
    rows=10
)

metric_selector = widgets.Dropdown(
    options=['LapTimeSeconds', 'SpeedI1', 'SpeedI2', 'SpeedFL', 'SpeedST'],
    value='LapTimeSeconds',
    description='Metric:'
)

plot_button = widgets.Button(
    description='Plot',
    button_style='success',
    icon='chart-line'
)

output = widgets.Output()

def on_plot_click(b):
    """Generate plot when button clicked."""
    with output:
        output.clear_output(wait=True)

        selected_drivers = driver_selector.value
        metric = metric_selector.value

        if not selected_drivers:
            display(HTML("<p>⚠️ Please select at least one driver</p>"))
            return

        # Create plot
        fig, ax = plt.subplots(figsize=(14, 7))
        colors = get_driver_color_mapping(session)
        laps = session.laps

        for driver in selected_drivers:
            driver_laps = laps[laps["Driver"] == driver]
            if metric in driver_laps.columns:
                ax.plot(
                    driver_laps["LapNumber"],
                    driver_laps[metric],
                    color=colors.get(driver),
                    label=driver,
                    linewidth=2,
                    marker='o',
                    markersize=4
                )

        ax.set_xlabel("Lap Number")
        ax.set_ylabel(metric)
        ax.set_title(f"{metric} Comparison - 2025 Bahrain Grand Prix")
        ax.legend()
        ax.grid(True, alpha=0.3)

        plt.tight_layout()
        plt.show()

plot_button.on_click(on_plot_click)

# Layout
controls = widgets.VBox([
    widgets.HTML("<h3>📊 Multi-Driver Comparison Tool</h3>"),
    driver_selector,
    metric_selector,
    plot_button
])

display(controls, output)
```

### 6. Memory Management

Handle large datasets efficiently in notebooks:

```python
import tif1

# Use the polars backend for this session (``config.set("lib", "polars")``
# would switch the default for every later session instead)
session = tif1.get_session(2025, "Bahrain Grand Prix", "Race", lib="polars")
session.load(telemetry=False)

# Check memory usage (polars DataFrames have estimated_size())
laps = session.laps
print(f"Laps DataFrame: {laps.estimated_size() / 1024 / 1024:.2f} MB")

# Load telemetry selectively
driver = session.get_driver("VER")
fastest_lap = driver.get_fastest_lap()  # one-row polars DataFrame

# Only load telemetry for specific lap
if not fastest_lap.is_empty():
    lap_number = int(fastest_lap["LapNumber"][0])
    lap = driver.get_lap(lap_number)
    tel = lap.telemetry
    print(f"Telemetry DataFrame: {tel.estimated_size() / 1024 / 1024:.2f} MB")
    del tel  # Clear large objects when done

del laps
```

**Memory Monitoring** (requires `psutil`):

```python
import tif1
from IPython.display import display, HTML
import psutil
import os

def display_memory_usage():
    """Display current memory usage."""
    process = psutil.Process(os.getpid())
    mem_mb = process.memory_info().rss / 1024 / 1024

    html = f"""
    <div style="border-left: 3px solid #FF9800; padding-left: 10px; margin: 10px 0;">
        <strong>Memory Usage:</strong> {mem_mb:.2f} MB
    </div>
    """
    display(HTML(html))

# Monitor memory during operations
display_memory_usage()

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
session.load(telemetry=False)

display_memory_usage()

# Load fastest-lap telemetry for the first five drivers
for driver_code in session.drivers_df["Driver"][:5]:
    driver = session.get_driver(driver_code)
    fastest = driver.get_fastest_lap()
    if not fastest.empty:
        lap_num = int(fastest['LapNumber'].iloc[0])
        lap = driver.get_lap(lap_num)
        tel = lap.telemetry

display_memory_usage()
```

```python
# Check if in notebook
from tif1.jupyter import _is_notebook

```

```python
import tif1

```
### Memory Issues

For large datasets in notebooks, use the polars backend. Pass `lib="polars"` for one session, or set the default for every session with `tif1.get_config().set("lib", "polars")`:

```python
import tif1

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race", lib="polars")
```

## Complete notebook example

```python
# Cell 1: Setup
import tif1
import matplotlib.pyplot as plt
from IPython.display import display
from tif1.plotting import setup_mpl, get_driver_color_mapping

setup_mpl()

# Cell 2: Load session
session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
session  # Rich display

# Cell 3: Explore drivers
drivers_df = session.drivers_df
print(f"Drivers: {len(drivers_df)}")
for driver_code in drivers_df["Driver"][:5]:
    driver = session.get_driver(driver_code)
    display(driver)

# Cell 4: Get fastest laps
fastest = session.get_fastest_laps(by_driver=True)
fastest[["Driver", "Team", "LapTimeSeconds", "Compound"]].head(10)

# Cell 5: Analyze specific driver
ver = session.get_driver("VER")
ver_laps = ver.laps

print(f"Total laps: {len(ver_laps)}")
print(f"Fastest: {ver_laps['LapTimeSeconds'].min():.3f}s")
print(f"Average: {ver_laps['LapTimeSeconds'].mean():.3f}s")

# Cell 6: Get telemetry
tel = ver.get_fastest_lap_tel()

if not tel.empty:
    print(f"Telemetry samples: {len(tel)}")
    print(f"Max speed: {tel['Speed'].max():.1f} km/h")
    if 'RPM' in tel.columns:
        print(f"Max RPM: {tel['RPM'].max()}")

# Cell 7: Plot telemetry
if not tel.empty:
    fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(14, 8))

    # Speed trace
    ax1.plot(tel['Distance'], tel['Speed'], linewidth=2)
    ax1.set_ylabel('Speed (km/h)')
    ax1.set_title('VER Fastest Lap - 2025 Bahrain Grand Prix')
    ax1.grid(True, alpha=0.3)

    # Throttle and brake
    ax2.plot(tel['Distance'], tel['Throttle'], label='Throttle', linewidth=2)
    if 'Brake' in tel.columns:
        ax2.fill_between(tel['Distance'], 0, 100, where=tel['Brake'] > 0,
                          alpha=0.3, color='red', label='Brake')
    ax2.set_xlabel('Distance (m)')
    ax2.set_ylabel('Throttle (%)')
    ax2.legend()
    ax2.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

# Cell 8: Compare drivers
drivers_to_compare = ["PIA", "RUS", "VER"]
colors = get_driver_color_mapping(session)

fig, ax = plt.subplots(figsize=(12, 6))

for driver_code in drivers_to_compare:
    driver_laps = session.laps[session.laps["Driver"] == driver_code]
    ax.plot(
        driver_laps["LapNumber"],
        driver_laps["LapTimeSeconds"],
        color=colors.get(driver_code),
        label=driver_code,
        linewidth=2,
        marker='o',
        markersize=4
    )

ax.set_xlabel('Lap Number')
ax.set_ylabel('Lap Time (s)')
ax.set_title('Lap Time Comparison - 2025 Bahrain Grand Prix')
ax.legend()
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```
