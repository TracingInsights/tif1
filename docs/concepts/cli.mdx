## Overview

The tif1 CLI gives access to Formula 1 data from the terminal. The CLI is built with [Typer](https://typer.tiangolo.com/) and [Rich](https://rich.readthedocs.io/). It prints formatted output with progress indicators and tables.

The CLI is designed for:
- **Quick data exploration** - Browse events, sessions, and drivers without writing code
- **Performance testing** - Benchmark data loading and cache performance
- **Cache management** - Inspect and manage the local data cache
- **Debugging** - Enable detailed logging to troubleshoot issues
- **Scripting** - Integrate F1 data into shell scripts and automation workflows

## Installation

The tif1 package installs the CLI automatically:

```bash
pip install tif1
```

After installation, the `tif1` command is available in the terminal. Verify the installation:

```bash
tif1 version
```

## Global Options

All commands support standard help output:

```bash
tif1 --help              # Show all available commands
tif1 events --help       # Show help for a specific command
```

## Commands Reference

### `events` - List Events for a Season

Display all Formula 1 events (Grand Prix weekends) for a specific year.

**Syntax:**
```bash
tif1 events <year>
```

**Arguments:**
- `year` (required): Season year (2018-current)

**Output:**
- Formatted table with event numbers and names
- Total event count for the season

**Examples:**

```bash
# List all 2025 events
tif1 events 2025

# List 2024 events
tif1 events 2024

# List 2018 events (earliest supported year)
tif1 events 2018
```

**Sample Output (`tif1 events 2025`):**
```text
          F1 Events 2025
┏━━━━┳━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃ #  ┃ Event                     ┃
┡━━━━╇━━━━━━━━━━━━━━━━━━━━━━━━━━━┩
│ 1  │ Australian Grand Prix     │
│ 2  │ Chinese Grand Prix        │
│ 3  │ Japanese Grand Prix       │
│ 4  │ Bahrain Grand Prix        │
...
│ 24 │ Abu Dhabi Grand Prix      │
│ 25 │ Pre-Season Testing        │
└────┴───────────────────────────┘

Total: 25 events
```

The list includes testing events, such as `Pre-Season Testing`. The total can be higher than the number of Grand Prix weekends.

**Use Cases:**
- Discover available events for a season
- Find the exact event name for use in other commands
- Check the schedule of a specific year

### `sessions` - List Sessions for an Event

Display all sessions available for a specific Grand Prix event.

**Syntax:**
```bash
tif1 sessions <year> <event>
```

**Arguments:**
- `year` (required): Season year (2018-current)
- `event` (required): Event name (use quotes for multi-word names)

**Output:**
- Formatted table with session numbers and names
- Typical sessions include: Practice 1, Practice 2, Practice 3, Qualifying, Sprint, Sprint Qualifying, Race

**Examples:**

```bash
# List sessions for 2025 Abu Dhabi GP
tif1 sessions 2025 "Abu Dhabi Grand Prix"

# List sessions for Monaco (single-word event names don't need quotes)
tif1 sessions 2024 Monaco

# List sessions for a sprint weekend
tif1 sessions 2024 "São Paulo Grand Prix"
```

**Sample Output (`tif1 sessions 2024 Monaco`):**
```text
   Monaco 2024
┏━━━┳━━━━━━━━━━━━┓
┃ # ┃ Session    ┃
┡━━━╇━━━━━━━━━━━━┩
│ 1 │ Practice 1 │
│ 2 │ Practice 2 │
│ 3 │ Practice 3 │
│ 4 │ Qualifying │
│ 5 │ Race       │
└───┴────────────┘
```

The table title repeats the event name as typed, not the resolved name.

**Use Cases:**
- Determine available sessions for an event
- Find the exact session name for data queries
- Identify sprint weekends (which have Sprint and Sprint Qualifying sessions)

### `drivers` - List Drivers in a Session

Display all drivers of a specific session, with their teams and car numbers. The rows are in classification order.

**Syntax:**
```bash
tif1 drivers <year> <event> <session>
```

**Arguments:**
- `year` (required): Season year (2018-current)
- `event` (required): Event name (use quotes for multi-word names)
- `session` (required): Session name (use quotes for multi-word names)

**Output:**
- Formatted table with driver codes, team names, and car numbers
- Total driver count
- Progress indicator during data loading

**Examples:**

```bash
# List drivers in 2025 Abu Dhabi GP Practice 1
tif1 drivers 2025 "Abu Dhabi Grand Prix" "Practice 1"

# List drivers in qualifying
tif1 drivers 2024 Monaco Qualifying

# List drivers in the race
tif1 drivers 2024 "British Grand Prix" Race
```

### `fastest` - Show Fastest Laps

Display the fastest lap times for all drivers or a specific driver in a session.

**Syntax:**
```bash
tif1 fastest <year> <event> <session> [OPTIONS]
```

**Arguments:**
- `year` (required): Season year (2018-current)
- `event` (required): Event name (use quotes for multi-word names)
- `session` (required): Session name (use quotes for multi-word names)

**Options:**
- `--driver <code>` or `-d <code>`: Filter to a specific driver (3-letter code, case-sensitive)

**Output:**
- **All drivers mode**: Sorted table of fastest laps with position, driver, team, and time
- **Single driver mode**: The fastest lap time of the driver
- Progress indicator during data loading

**Examples:**

```bash
# Show fastest laps for all drivers in qualifying
tif1 fastest 2025 "Abu Dhabi Grand Prix" Qualifying

# Show Verstappen's fastest lap
tif1 fastest 2025 "Abu Dhabi Grand Prix" Qualifying --driver VER

# Show Hamilton's fastest lap (short option)
tif1 fastest 2024 Monaco Qualifying -d HAM

# Show fastest laps in practice session
tif1 fastest 2024 "British Grand Prix" "Practice 1"

# Show fastest laps in the race
tif1 fastest 2024 "Italian Grand Prix" Race
```

**Sample Output (All Drivers, `tif1 fastest 2025 Bahrain Race`):**
```text
Loading session... ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 100% 0:00:00
     Fastest Laps - Bahrain 2025 - Race
┏━━━━━┳━━━━━━━━┳━━━━━━━━━━━━━━━━━┳━━━━━━━━━┓
┃ Pos ┃ Driver ┃ Team            ┃ Time    ┃
┡━━━━━╇━━━━━━━━╇━━━━━━━━━━━━━━━━━╇━━━━━━━━━┩
│ 1   │ PIA    │ McLaren         │ 95.140s │
│ 2   │ RUS    │ Mercedes        │ 95.518s │
│ 3   │ NOR    │ McLaren         │ 95.728s │
│ 4   │ LEC    │ Ferrari         │ 96.132s │
...
└─────┴────────┴─────────────────┴─────────┘
```

**Sample Output (Single Driver, `-d VER`):**
```text
Loading session... ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 100% 0:00:00
VER fastest lap: 96.167s
```

A lap counts when its `LapTime` is set and the lap is not deleted. A driver without such a lap is not in the table. With `--driver`, such a driver gets `No valid laps for <code>`. An unknown code exits with `DriverNotFoundError`.

**Use Cases:**
- Compare driver performance in a session
- Identify the fastest driver in qualifying or practice
- Analyze individual driver lap times
- Generate performance reports for specific drivers

### `cache-info` - Show Cache Information

Display detailed information about the local tif1 cache: location, file count, and total size.

**Syntax:**
```bash
tif1 cache-info
```

**Arguments:**
None

**Output:**
- Cache directory path
- Number of cache files
- Total cache size in megabytes

**Examples:**

```bash
# Show cache information
tif1 cache-info
```

**Sample Output:**
```text
Cache location: /home/user/.cache/tif1
Cache files: 3
Total size: 145.67 MB
```

**Use Cases:**
- Monitor cache disk usage
- Verify cache location
- Determine if cache needs cleaning
- Troubleshoot cache-related issues

**Cache Details:**

The tif1 cache uses SQLite with Write-Ahead Logging (WAL):
- **Main cache database**: `cache.sqlite` - Stores session data, lap data, and metadata
- **WAL files**: `cache.sqlite-wal` and `cache.sqlite-shm` - Transaction logs for concurrent access
- **In-memory cache**: LRU caches for frequently accessed data (not shown in file count)

The cache stores:
- Event schedules
- Session metadata
- Lap data
- Telemetry data
- Weather information
- Race control messages

### `cache-clear` - Clear Cache

Remove all cached data to force fresh data downloads.

**Syntax:**
```bash
tif1 cache-clear [OPTIONS]
```

**Options:**
- `--yes` or `-y`: Skip confirmation prompt (useful for scripts)

**Output:**
- Confirmation prompt (unless `--yes` is used)
- Success or cancellation message

**Examples:**

```bash
# Clear cache with confirmation prompt
tif1 cache-clear

# Clear cache without confirmation (for scripts)
tif1 cache-clear --yes

# Clear cache without confirmation (short option)
tif1 cache-clear -y
```

**Sample Output (With Confirmation):**
```text
Are you sure you want to clear the cache? [y/N]: y
Cache cleared successfully!
```

**Sample Output (Without Confirmation):**
```text
Cache cleared successfully!
```

**Sample Output (Cancelled):**
```text
Cache clear cancelled
```

**Use Cases:**
- Force fresh data downloads after data corrections
- Troubleshoot cache corruption issues
- Reset cache during development/testing

**Warning:** Clearing the cache removes all local data. The next access downloads all data again. The download time depends on the network speed and the amount of data requested.

The command deletes the rows of every cache table. The `cache.sqlite` file keeps its size, and SQLite reuses the free pages for new data. To get the disk space back, delete the cache directory.

### `debug` - Debug Mode Session Loading

Load a session with debug-level logging enabled to troubleshoot issues or understand data loading behavior.

**Syntax:**
```bash
tif1 debug <year> <event> <session>
```

**Arguments:**
- `year` (required): Season year (2018-current)
- `event` (required): Event name (use quotes for multi-word names)
- `session` (required): Session name (use quotes for multi-word names)

**Output:**
- Debug logs on stderr, showing:
  - CDN request URLs
  - Cache hits and cache writes
  - Lap loading steps
- Session summary on stdout (driver count, lap count)
- Progress indicator during loading

**Examples:**

```bash
# Debug session loading
tif1 debug 2025 "Abu Dhabi Grand Prix" "Practice 1"

# Debug qualifying session
tif1 debug 2024 Monaco Qualifying

# Debug race session
tif1 debug 2024 "British Grand Prix" Race
```

**Sample Output (`tif1 debug 2025 Bahrain Race` with an empty cache, shortened):**

- Debug network connectivity problems
- Report detailed information in bug reports

**Debug Information Includes:**
- Cache operations (SQLite hits, frame-tier hits, writes)
- CDN requests (source name and URL)
- Retry, CDN fallback, and circuit breaker messages
- HTTP connection pool statistics

## Configuration

The CLI reads all tif1 configuration options from environment variables and from the `.tif1rc` configuration file.

### Environment Variables

Key environment variables that affect CLI behavior:

```bash
# Cache location
export TIF1_CACHE_DIR="$HOME/tif1-cache"

# Enable/disable caching
export TIF1_ENABLE_CACHE=true

# Network timeout (seconds)
export TIF1_TIMEOUT=30

# Maximum retry attempts
export TIF1_MAX_RETRIES=3

# Backend library (pandas or polars)
export TIF1_LIB=pandas
```

No environment variable sets the log level. Use the `debug` command for debug logs.

### Configuration File

Create a `.tif1rc` file in the home directory for persistent configuration:

```json
{
  "cache_dir": "/custom/cache/path",
  "timeout": 60,
  "max_retries": 5,
  "enable_cache": true,
  "lib": "pandas"
}
```

See the [Environment Variables documentation](/reference/environment-variables) for complete details.

## Advanced Usage

### Scripting and Automation

The CLI is designed for use in shell scripts and automation workflows:

```bash
#!/bin/bash
# Script to check fastest laps for all 2025 qualifying sessions.
# The events table is for people to read; get plain event names from Python
# (one per line, testing excluded) so multi-word names stay intact.

python -c 'import tif1; print("\n".join(tif1.get_event_schedule(2025, include_testing=False)["EventName"]))' |
while IFS= read -r event; do
  echo "Processing: $event"
  tif1 fastest 2025 "$event" Qualifying
done
```

### Performance Testing

Use the CLI to benchmark cache performance:

```bash
# First run (cold cache)
time tif1 drivers 2025 "Abu Dhabi Grand Prix" Race

# Second run (warm cache)
time tif1 drivers 2025 "Abu Dhabi Grand Prix" Race
```

### Pipeline Integration

Combine CLI commands with other tools:

```bash
# Save the fastest-lap table to a text file
tif1 fastest 2025 Monaco Qualifying > fastest_laps.txt

# Count the drivers with a timed lap
tif1 fastest 2025 Monaco Qualifying | grep -c "s │"
```

## Tips and Best Practices

### Event and Session Names

- Use quotes for multi-word names: `"Abu Dhabi Grand Prix"`
- Single-word event names do not need quotes: `Monaco`
- Session names are case-insensitive: `Qualifying`, `qualifying`, and `Q` all work
- Use `tif1 events` and `tif1 sessions` to find exact names

### Performance Optimization

- The first data access is slower (cold cache)
- Subsequent accesses are much faster (warm cache)
- Use `cache-clear` sparingly to maintain performance
- Use the `debug` command to see which CDN or cache tier serves each file

### Error Handling

- If a command fails, use the `debug` command for detailed error information
- Check the internet connection for network-related errors
- Verify event and session names are correct
- Ensure the year is within the supported range (2018-current)

### Cache Location

- Default cache location varies by OS:
  - **Linux/other POSIX**: `~/.cache/tif1` or `~/.tif1`
  - **macOS**: `~/Library/Caches/tif1`
  - **Windows**: `%LOCALAPPDATA%\Temp\tif1`
- Override the location with the `TIF1_CACHE_DIR` environment variable
- Cache permissions are restricted to the user (0o700)

## Troubleshooting

### Command Not Found

If the `tif1` command is not found after installation:

```bash
# Verify installation
pip show tif1

# Show the site-packages directory of the installation
pip show tif1 | grep Location

# Reinstall if necessary
pip install --force-reinstall tif1
```

### Network Errors

If network errors occur:

```bash
# Check with debug mode
tif1 debug 2025 Monaco Race

# Verify internet connection
ping cdn.jsdelivr.net

# Try increasing timeout
export TIF1_TIMEOUT=60
tif1 drivers 2025 Monaco Race
```

### Cache Issues

If the cache is corrupt:

```bash
# Clear cache and retry
tif1 cache-clear -y
tif1 drivers 2025 Monaco Race

# Check cache location
tif1 cache-info
```

### Data Not Found

If data is not available:

```bash
# Verify event exists
tif1 events 2025

# Verify session exists
tif1 sessions 2025 "Monaco Grand Prix"

# Check if session has completed (future sessions have no data)
```
