Acceleration maps show the g-forces on the car around the circuit. The map on this page shows longitudinal acceleration (braking and acceleration). The last section explains how to get lateral acceleration (cornering forces).

<img src="/assets/track_acceleration_map.png" alt="Track acceleration map showing g-forces" />

## Understanding Acceleration Data

- **Longitudinal acceleration:** Forward/backward forces during acceleration and braking
- **Lateral acceleration:** Sideways forces during cornering
- Measured in g-forces (1g = 9.81 m/s²)

## Loading the Session

```python
import tif1
import matplotlib.pyplot as plt
from matplotlib.collections import LineCollection
import numpy as np

# Load session
session = tif1.get_session(2023, 'Suzuka', 'Q')
fastest_lap = session.laps.pick_fastest()
```

## Calculating Longitudinal Acceleration

Longitudinal acceleration is derived from speed changes over time.

```python
# Get telemetry
telemetry = fastest_lap.get_car_data()

# Calculate acceleration from speed
speed_ms = telemetry['Speed'] / 3.6  # Convert km/h to m/s
time_s = telemetry['Time'].dt.total_seconds()

# Compute derivative (acceleration)
lon_acc = np.gradient(speed_ms, time_s) / 9.81  # Convert to g-forces

# Extract position
x = telemetry['X']
y = telemetry['Y']
```

## Creating the Acceleration Map

```python
# Prepare segments
points = np.array([x, y]).T.reshape(-1, 1, 2)
segments = np.concatenate([points[:-1], points[1:]], axis=1)

# Create plot
fig, ax = plt.subplots(figsize=(12, 10))

# Color-coded by acceleration
norm = plt.Normalize(lon_acc.min(), lon_acc.max())
lc = LineCollection(segments, cmap='RdBu_r', norm=norm, linewidth=4)
lc.set_array(lon_acc)
line = ax.add_collection(lc)

# Colorbar
cbar = plt.colorbar(line, ax=ax, label='Longitudinal Acceleration (g)')

# Format
ax.set_aspect('equal')
ax.axis('off')
plt.suptitle(f"{session.event['EventName']} {session.event.year} - Acceleration Map")
plt.tight_layout()
plt.show()
```

## Parameters

The native chart always draws the fastest lap of the session, so it has no driver or lap filters. Change the color scale with `cmap`, or write the figure straight to a file with `save_path`:

```python
import tif1

# Custom colormap, saved directly to a file
fig, ax = tif1.plot_track_acceleration_map(
    2023, 'Suzuka', 'Q',
    cmap='seismic',
    save_path='track_acceleration_map.png',
    dpi=300,
)
plt.show()
```

The default `cmap='RdBu_r'` matches the chart above.

## Complete Example

The whole workflow above is wrapped in a single native function:

```python
import tif1
import matplotlib.pyplot as plt

# One call: loads the session, computes acceleration, and draws the track map
fig, ax = tif1.plot_track_acceleration_map(2023, 'Suzuka', 'Q')
plt.show()

# Or save straight to a file
# tif1.plot_track_acceleration_map(2023, 'Suzuka', 'Q', save_path='track_acceleration_map.png')
```

## Interpreting the Colors

- **Red:** The high end of the range (strongest acceleration)
- **Blue:** The low end of the range (heaviest braking)
- **White/neutral:** The middle of the range, not zero

The color scale runs from the lowest value to the highest value of the lap. On this lap, the values go from about -3.8 g under braking to about +1.9 g under acceleration. The neutral color is at the midpoint, about -0.9 g, which is light braking.

## Lateral Acceleration

Lateral acceleration comes from the speed and the track curvature. The curvature comes from the `X` and `Y` coordinates, which are in units of 1/10 m. A plain `np.gradient` of these coordinates amplifies the telemetry noise and gives values that are not realistic.

The [G-G diagram](/tutorials/gg-diagram) and [telemetry comparison](/tutorials/telemetry-comparison) tutorials use a smooth-derivative approach for both acceleration components. Use that approach for lateral acceleration.
