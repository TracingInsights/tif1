tif1 exports F1 data to various formats for use in other tools, databases, and analysis platforms.

## Export to CSV

The simplest way to export data for use in Excel, Google Sheets, or other tools.

```python
import tif1

session = tif1.get_session(2025, "Monaco Grand Prix", "Race")
laps = session.laps

# Export all laps to CSV
laps.to_csv("monaco_race_laps.csv", index=False)

# Export specific driver's laps
ver = session.get_driver("VER")
ver.laps.to_csv("verstappen_laps.csv", index=False)

# Export telemetry
fastest_lap = ver.get_fastest_lap()
telemetry = ver.get_lap(int(fastest_lap["LapNumber"].iloc[0])).telemetry
telemetry.to_csv("verstappen_fastest_telemetry.csv", index=False)
```

<Note>
On pandas, the laps frame carries a leading `index` column from the source data. `to_csv(index=False)`
writes it as a normal column. Drop it with `laps.drop(columns="index")` when it is not needed.
</Note>

## Export to Parquet

Parquet is a columnar storage format. It is more efficient than CSV for large datasets. On the pandas backend, `to_parquet` uses `pyarrow`, which `pip install tif1` installs. The polars backend writes Parquet natively with `write_parquet`; see [Working with Polars Backend](#working-with-polars-backend).

```python
# Export to Parquet (pandas backend)
laps.to_parquet("monaco_race_laps.parquet")

# snappy is the default codec; zstd gives a smaller file
laps.to_parquet("monaco_race_laps.parquet", compression="zstd")

# Read back
import pandas as pd
laps_loaded = pd.read_parquet("monaco_race_laps.parquet")
```

## Export to JSON

For web applications or APIs. Pass `date_format="iso"` so that timedelta columns such as
`LapTime` are written as ISO strings. The default epoch format is deprecated in pandas 3.

```python
# Export to JSON
laps.to_json("monaco_race_laps.json", orient="records", indent=2, date_format="iso")

# Compact format
laps.to_json("monaco_race_laps_compact.json", orient="records", date_format="iso")

# Split format (smaller file: column names are written once)
laps.to_json("monaco_race_laps_split.json", orient="split", date_format="iso")
```

## Export to Excel

Create Excel files with multiple sheets.

<Note>
This section requires the optional Excel engine. Install it with `pip install openpyxl`.
</Note>

Excel has no duration type. pandas writes timedelta columns such as `LapTime` as fractions of a day.
Use the float `LapTimeSeconds` column for lap times in seconds.

```python
# Single sheet
laps.to_excel("monaco_race.xlsx", sheet_name="Laps", index=False)

# Multiple sheets
with pd.ExcelWriter("monaco_race_full.xlsx") as writer:
    session.laps.to_excel(writer, sheet_name="Laps", index=False)
    session.weather.to_excel(writer, sheet_name="Weather", index=False)
    session.drivers_df.to_excel(writer, sheet_name="Drivers", index=False)
    session.race_control_messages.to_excel(writer, sheet_name="Messages", index=False)
```

## Export to SQL Database

Store data in a relational database for complex queries.

<Note>
SQLite treats column names as case-insensitive. The laps DataFrame contains both
`Team` and `team` source columns. Drop the duplicate before the SQL write.
SQL databases have no timedelta type. pandas writes timedelta columns as integer
nanoseconds and shows a warning. Convert them to float seconds before the write.
</Note>

```python
import sqlite3
import pandas as pd

# Create database connection
conn = sqlite3.connect("f1_data.db")

# Drop case-insensitive duplicate columns (Team and team) before writing to SQLite
laps_sql = laps.loc[:, ~laps.columns.str.lower().duplicated()].copy()

# SQL has no timedelta type: store the time columns as float seconds
td_cols = laps_sql.select_dtypes("timedelta").columns
laps_sql[td_cols] = laps_sql[td_cols].apply(lambda s: s.dt.total_seconds())

# Export laps
laps_sql.to_sql("laps", conn, if_exists="replace", index=False)

# Export telemetry for multiple drivers
for driver in ["VER", "HAM", "LEC"]:
    driver_obj = session.get_driver(driver)
    fastest = driver_obj.get_fastest_lap()
    tel = driver_obj.get_lap(int(fastest["LapNumber"].iloc[0])).telemetry
    tel = tel.assign(Time=tel["Time"].dt.total_seconds())  # lap-relative seconds
    tel.to_sql(f"telemetry_{driver}", conn, if_exists="replace", index=False)

conn.close()

# Query the data
conn = sqlite3.connect("f1_data.db")
query = """
SELECT Driver, MIN(LapTime) AS FastestLap, AVG(LapTime) AS AvgLap
FROM laps
WHERE LapTime IS NOT NULL
GROUP BY Driver
ORDER BY FastestLap
"""
results = pd.read_sql_query(query, conn)
print(results)
conn.close()
```

## Export to PostgreSQL

For production databases.

<Note>
This section requires the optional SQL toolkit and a PostgreSQL driver.
Install them with `pip install sqlalchemy psycopg2-binary`. The `postgresql+psycopg2://` URL selects that driver.
</Note>

```python
from sqlalchemy import create_engine

# Create engine
engine = create_engine("postgresql+psycopg2://user:password@localhost:5432/f1_data")

# Export data; laps_sql comes from the SQLite example (time columns in seconds)
laps_sql.to_sql("laps", engine, if_exists="replace", index=False)
weather = session.weather
weather.assign(Time=weather["Time"].dt.total_seconds()).to_sql(
    "weather", engine, if_exists="replace", index=False
)
```

## Export for Machine Learning

Prepare data for ML frameworks.

### NumPy Arrays

Convert timedelta columns to float seconds first. ML frameworks expect
numeric arrays. Cast the boolean `Brake` channel to float so that the array is numeric.

```python
import numpy as np

# Convert to numpy for scikit-learn, tensorflow, pytorch
time_cols = ["LapTime", "Sector1Time", "Sector2Time", "Sector3Time"]
lap_features = laps[time_cols].apply(lambda s: s.dt.total_seconds()).to_numpy()

# Save as .npy file
np.save("lap_features.npy", lap_features)

# Telemetry as numpy (Brake is boolean; cast every channel to float64)
tel_array = telemetry[["Speed", "Throttle", "Brake", "RPM"]].astype("float64").to_numpy()
np.save("telemetry_features.npy", tel_array)
```

### HDF5 Format

Efficient for large numerical datasets.

<Note>
This section requires the optional HDF5 engine. Install it with `pip install tables`.
</Note>

```python
# HDF5 does not support pandas nullable dtypes; convert them to native dtypes first
def to_hdf_compatible(df):
    convert = {}
    for col in df.columns:
        dtype = str(df[col].dtype)
        if dtype == "Int64":
            convert[col] = "int64"
        elif dtype == "boolean":
            convert[col] = "bool"
    return df.astype(convert)

# Export to HDF5 (format="table" supports categorical columns)
to_hdf_compatible(laps).to_hdf("monaco_race.h5", key="laps", mode="w", format="table")
to_hdf_compatible(telemetry).to_hdf("monaco_race.h5", key="telemetry", mode="a", format="table")

# Read back
laps_loaded = pd.read_hdf("monaco_race.h5", key="laps")
```

## Batch Export Multiple Sessions

Export an entire race weekend or season.

```python
import tif1

def export_weekend(year, gp, output_dir="data"):
    """Export all sessions from a race weekend."""
    import os
    os.makedirs(output_dir, exist_ok=True)

    sessions = tif1.get_sessions(year, gp)

    for session_name in sessions:
        try:
            session = tif1.get_session(year, gp, session_name)

            # Create safe filename
            safe_name = session_name.replace(" ", "_").lower()
            filename = f"{output_dir}/{year}_{gp.replace(' ', '_')}_{safe_name}.parquet"

            # Export laps
            session.laps.to_parquet(filename)
            print(f"Exported: {filename}")

        except Exception as e:
            print(f"Failed to export {session_name}: {e}")

# Export Monaco 2025 weekend
export_weekend(2025, "Monaco Grand Prix", "monaco_2025")
```

### Export Entire Season

```python
def export_season(year, output_dir="season_data"):
    """Export all races from a season."""
    import os
    os.makedirs(output_dir, exist_ok=True)

    # The schedule is a DataFrame; loop over the EventName column
    events = tif1.get_event_schedule(year, include_testing=False)["EventName"]

    for event in events:
        print(f"Processing {event}...")
        sessions = tif1.get_sessions(year, event)

        for session_name in sessions:
            if session_name == "Race":  # Only export races
                try:
                    session = tif1.get_session(year, event, session_name)
                    safe_event = event.replace(" ", "_").replace("/", "_")
                    filename = f"{output_dir}/{year}_{safe_event}_race.parquet"
                    session.laps.to_parquet(filename)
                    print(f"  ✓ {event} Race")
                except Exception as e:
                    print(f"  ✗ {event} Race: {e}")

# Export 2024 season
export_season(2024, "2024_season")
```

## Working with Polars Backend

The polars backend gives additional export options.

```python
import polars as pl
import polars.selectors as cs

session = tif1.get_session(2025, "Monaco Grand Prix", "Race", lib="polars")
laps = session.laps

# Polars writes Parquet natively (zstd by default)
laps.write_parquet("monaco_polars.parquet")
# CSV has no duration type: write the Duration columns as float seconds
laps.with_columns(cs.duration().dt.total_milliseconds() / 1000).write_csv("monaco_polars.csv")
laps.write_json("monaco_polars.json")
laps.write_ipc("monaco_polars.arrow")  # Apache Arrow format

# Read back; `columns` reads only the listed columns
laps_loaded = pl.read_parquet("monaco_polars.parquet")
subset = pl.read_parquet(
    "monaco_polars.parquet", columns=["Driver", "LapNumber", "LapTimeSeconds"]
)

# Convert to pandas if needed
laps_pandas = laps.to_pandas()
```

## Export Telemetry for All Drivers

Efficiently export telemetry for multiple drivers.

```python
def export_all_telemetry(session, output_dir="telemetry"):
    """Export the fastest-lap telemetry of every driver."""
    import os
    os.makedirs(output_dir, exist_ok=True)

    # Use parallel fetching for speed
    tels = session.get_fastest_laps_tels(by_driver=True)

    for driver, tel in tels.groupby("Driver"):
        filename = f"{output_dir}/{driver}_fastest.parquet"
        tel.to_parquet(filename)
        print(f"Exported: {driver}")

    return tels["Driver"].nunique()

session = tif1.get_session(2025, "British Grand Prix", "Qualifying")
count = export_all_telemetry(session)
print(f"Exported telemetry for {count} drivers")
```

## Best Practices

<CardGroup cols={2}>
  <Card title="Use Parquet" icon="file">
    A race laps table is roughly 3-4x smaller as Parquet than as CSV, and faster to read/write.
  </Card>
  <Card title="Batch Operations" icon="layer-group">
    Use async loading and batch exports for multiple sessions.
  </Card>
  <Card title="Compression" icon="compress">
    pandas compresses Parquet with snappy by default. Use zstd or gzip for smaller files.
  </Card>
  <Card title="Type Preservation" icon="database">
    Parquet preserves timedelta and categorical columns. CSV writes them as text.
  </Card>
</CardGroup>

<Tip>
  For large-scale data pipelines, consider the polars lib with Arrow/Parquet formats for the fastest export.
</Tip>
