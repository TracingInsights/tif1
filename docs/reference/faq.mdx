## General Questions

### What is tif1?

tif1 is a Python library for Formula 1 data analysis. It provides fast access to timing, telemetry, and weather data from 2018-current, and to Ergast results, lap times, pit stops and standings from 1950-current. Parallel async loading is more than 3x faster than sequential fetching in the benchmark suite.

### How is tif1 different from fastf1?

tif1 is designed as a faster alternative to fastf1 with API compatibility. Key differences:

- **Speed**: Parallel data loading with async/HTTP/2 (3x+ vs sequential, benchmark-validated)
- **Backends**: Supports both pandas and polars
- **Caching**: SQLite + memory LRU vs file-based pickle
- **Data Source**: TracingInsights CDN (timing, telemetry) and the TracingInsights Stats repository (Ergast tables, jolpica-f1 only as fallback) vs live timing + jolpica-f1
- **Focus**: Historical data only (no live timing)

### Is tif1 free to use?

Yes, tif1 is open source under the MIT License. Use it freely for personal, academic, or commercial projects.

### What data is available?

- Lap times and sectors (2018-current)
- Official classifications, pit stops and championship standings (1950-current, Ergast data)
- Telemetry (speed, throttle, brake, RPM, gear, DRS)
- Position data (X, Y, Z coordinates)
- Acceleration data (X, Y, Z axes)
- Weather data
- Tire compounds and strategy
- Race control messages
- Driver metadata

## Installation & Setup

### How do I install tif1?

```bash
pip install tif1
```



### What Python version do I need?

Python 3.11 or higher is required. Versions 3.11 through 3.15 are tested in CI.

On Python 3.14 and later, the cache uses the standard-library `compression.zstd` module instead of the `zstandard` package. On Python 3.15, the `lz4` package is not installed because it has no 3.15 wheels yet. The frame cache uses zstd instead. Cached payloads read on every version. On Python 3.15, a cached frame written with lz4 is a cache miss. tif1 rebuilds it from the cached payload.

### Do I need an API key?

No, tif1 does not require any API keys or authentication. All data is publicly available via the TracingInsights CDN.

### Where is data cached?

By default, data uses FastF1-style OS-specific cache locations: Windows `%LOCALAPPDATA%/Temp/tif1`, macOS `~/Library/Caches/tif1`, and Linux/other POSIX `~/.cache/tif1` when `~/.cache` exists (otherwise `~/.tif1`). Change this location in the `.tif1rc` file or with `TIF1_CACHE_DIR`.

## Data Access

### Why is my first load slow?

The first access to a session downloads data from the CDN. Later loads read the local cache. `session.laps` already fetches the lap payloads in parallel. Inside a running event loop, use `await session.laps_async()` instead.

### How do I load data faster?

1. Keep caching enabled (default)
2. Enable the polars lib: `lib="polars"`
3. Use batch telemetry fetching: `session.get_fastest_laps_tels()`

### Can I access live timing data?

No, tif1 focuses on historical data (timing and telemetry 2018-current, Ergast results 1950-current). For live timing, use fastf1.

### How recent is the data?

The TracingInsights data repositories publish a session shortly after it ends. The timing and telemetry files are generated with fastf1 and are available in under a minute after fastf1 has the data. A session that is not published yet raises `DataNotFoundError`. The Ergast classification of a round appears in the Stats repository a few hours after jolpica-f1 has it; until then `session.results` is merged from jolpica-f1.

### Why am I getting DataNotFoundError?

Common causes:
- The data has not been published yet (check whether the session ended recently)
- The session did not take place (cancelled or postponed)
- A driver code or lap number does not exist in the session (`DriverNotFoundError`, `LapNotFoundError`)

An event name that matches no event of that season raises a different error. `get_session` raises `EventNotFoundError`, a `ValueError` subclass, with the message `No event matching '<name>' in <year>`. An event that is not on the calendar of that season, for example `"Suzuka"` in 2021, raises `EventNotInSeasonError`, a subclass of `EventNotFoundError`.

tif1 resolves circuit, city, and country names such as `"Spa"` or `"Silverstone"` to the correct event. A misspelled event name such as `"Monacco"` does not raise: tif1 corrects it to the closest event name and logs a warning. Check the result with `session.event["EventName"]`. A name that resembles no event, such as `"Paris"`, raises `EventNotFoundError`. A session name that does not exist raises `ValueError` and lists the available session names.

## Performance

### How can I reduce memory usage?

1. Use the polars lib
2. Process drivers one at a time instead of loading all at once
3. Delete DataFrames when done: `del laps`
4. Use categorical dtypes (automatic for `Driver`, `Team`, `Compound`, and `TrackStatus` on pandas)

### Why is polars faster?

Polars is written in Rust and uses:
- Better parallelization across CPU cores
- More efficient memory layout
- Lazy evaluation for query optimization
- Native Arrow format

### Can I use multiple backends in one script?

Yes, each session can use a different backend:

```python
import tif1

session1 = tif1.get_session(2025, "Monaco Grand Prix", "Race", lib="pandas")
session2 = tif1.get_session(2025, "Italian Grand Prix", "Race", lib="polars")
```

## Errors & Troubleshooting

### I Get a NetworkError

Possible causes:
- Internet connection issues
- CDN is temporarily down (rare)
- Firewall blocking the CDN hosts (jsDelivr, Hugging Face, StaticDelivr)

Try:
1. Check the internet connection
2. Reset the circuit breaker: `tif1.reset_circuit_breaker()`
3. Enable debug logging: `tif1.setup_logging(logging.DEBUG)`

### The Cache Is Corrupted

Clear the cache and re-download:

```python
tif1.get_cache().clear()
```

### Column Names Do Not Match fastf1

tif1 uses the fastf1 column names, which are mostly PascalCase, for example `LapTime` and `Speed`. The raw JSON keys, such as `time`, are not column names. The laps table also keeps the lower-case source columns `drv`, `team`, and `ms1` to `ms3`. Use the exact column names shown in the [Data Schema Reference](/reference/data-schema).

## API & Usage

### Do I need to call session.load()?

No, tif1 uses lazy loading. Data is fetched automatically at first access:

```python
session = tif1.get_session(2025, "Monaco Grand Prix", "Race")
laps = session.laps  # Data fetched here
```

For explicit control over the data that is fetched, use `session.load()`.

### How do I get telemetry for all drivers?

Use the optimized batch method:

```python
# Parallel loading - faster than sequential (3x+ in benchmarks)
# One DataFrame with a Driver column; group by Driver to split it
tels = session.get_fastest_laps_tels(by_driver=True)
for driver, tel in tels.groupby("Driver"):
    print(driver, len(tel))
```

### Can I filter by lap number?

Yes, use standard DataFrame filtering:

```python
import polars as pl

# pandas
lap_10 = laps[laps["LapNumber"] == 10]

# polars
laps_pl = tif1.get_session(2025, "Monaco Grand Prix", "Race", lib="polars").laps
lap_10_pl = laps_pl.filter(pl.col("LapNumber") == 10)
```

### Why does `laps["LapTime"] < 90` fail?

`LapTime` is a `timedelta64[ns]` column on pandas and a `Duration` column on polars. On polars, `pl.col("LapTime") < 90` compares nanoseconds, so it selects no lap. Compare `LapTimeSeconds`, which is a float on both backends:

```python
# pandas
fast = laps[laps["LapTimeSeconds"] < 90]

# polars
fast_pl = laps_pl.filter(pl.col("LapTimeSeconds") < 90)
```

On pandas, `laps[laps["LapTime"] < pd.Timedelta(seconds=90)]` also works. On polars, `laps_pl.filter(pl.col("LapTime") < pl.duration(seconds=90))` does. See [Column types by backend](/concepts/backends#column-types-by-backend).

### How do I get weather data?

Weather is automatically included in the laps DataFrame:

```python
laps = session.laps
print(laps[["LapNumber", "Driver", "AirTemp", "TrackTemp"]])
```

Or access it directly:

```python
weather = session.weather
```

`Time` is `timedelta64[ns]` on pandas and `Duration("ns")` on polars. `Rainfall` is a nullable boolean on both backends. When the weather payload cannot be converted, tif1 logs a warning and returns an empty DataFrame. See [Empty Weather or Race Control Table](/reference/troubleshooting#empty-weather-or-race-control-table).

## Data Quality

### Are lap times accurate?

Lap times come from the official timing data that FastF1 reads. For Race sessions, the data pipeline replaces them with the official Ergast/Jolpica lap times where available.

### Why are some lap times missing?

Lap times can be missing due to:
- Pit stops
- Timing system issues
- Very slow laps (FastF1 can drop laps slower than 2:30)

A lap deleted for track limits keeps its `LapTime`. The `Deleted` column flags it, and the fastest-lap functions skip it.

For Race sessions, the data pipeline adds laps that FastF1 drops, such as lap 1, from Ergast/Jolpica. tif1 itself does not fill gaps.

### Is telemetry data validated?

Only on request. Pydantic validation is off by default. Set `TIF1_VALIDATE_TELEMETRY=true` and `TIF1_ULTRA_COLD_START=false` to validate downloaded telemetry. A payload that fails validation raises `InvalidDataError`. See [Environment Variables](/reference/environment-variables).

## Advanced Usage

### Can I use tif1 in production?

Yes, tif1 is designed for production use with:
- Typed exceptions rooted at `TIF1Error`
- Circuit breaker pattern
- Automatic retries
- SQLite caching for reliability

### How do I export data?

On the pandas backend, use the standard pandas export methods. On polars, use `write_csv`, `write_parquet`, and `write_json`.

```python
import sqlite3

laps.to_csv("data.csv")
laps.to_parquet("data.parquet")
laps.to_json("data.json", date_format="iso")

# SQLite column names are case-insensitive: drop the lower-case duplicates first
laps_sql = laps.loc[:, ~laps.columns.str.lower().duplicated()].copy()

# SQL has no timedelta type: store the time columns as float seconds
td_cols = laps_sql.select_dtypes("timedelta").columns
laps_sql[td_cols] = laps_sql[td_cols].apply(lambda s: s.dt.total_seconds())

conn = sqlite3.connect("f1_data.db")
laps_sql.to_sql("laps", conn, if_exists="replace", index=False)
conn.close()
```

See [Data Export](/tutorials/data-export) for Excel, HDF5, and PostgreSQL.

### Can I use tif1 with Jupyter?

Yes, tif1 has built-in Jupyter support with rich HTML displays for Session, Driver, and Lap objects.

### Does tif1 work with async frameworks?

Yes, tif1 uses asyncio internally and provides async methods:

```python
import asyncio

async def main():
    session = tif1.get_session(2025, "Monaco Grand Prix", "Race")
    return await session.laps_async()

laps = asyncio.run(main())
```

Inside a running event loop, such as a Jupyter cell, call `await session.laps_async()` directly.

### How do I analyze tire degradation?

Tire degradation analysis requires tracking lap times over tire life:

```python
import tif1
import matplotlib.pyplot as plt
from scipy import stats

session = tif1.get_session(2025, "Bahrain Grand Prix", "Race")
laps = session.laps

# Filter for a specific driver and stint
driver_laps = laps[
    (laps["Driver"] == "VER") &
    (laps["Stint"] == 2) &
    (laps["PitInTime"].isna())
]

# Plot lap time vs tire life
# LapTime is a timedelta column; LapTimeSeconds holds float seconds
plt.scatter(driver_laps["TyreLife"], driver_laps["LapTimeSeconds"])

# Add trend line
slope, intercept, r_value, _, _ = stats.linregress(
    driver_laps["TyreLife"],
    driver_laps["LapTimeSeconds"]
)
print(f"Degradation: {slope:.3f} seconds per lap")
print(f"R²: {r_value**2:.3f}")

plt.xlabel("Tire Life (laps)")
plt.ylabel("Lap Time (s)")
plt.title(f"Tire Degradation - {driver_laps['Compound'].iloc[0]} Compound")
plt.show()
```

### How do I compare two drivers' telemetry?

Load the fastest lap of each driver and plot the telemetry:

```python
import tif1

session = tif1.get_session(2025, "Monaco Grand Prix", "Qualifying")

# Get fastest laps for both drivers
ver_fastest = session.get_driver("VER").get_fastest_lap()
lec_fastest = session.get_driver("LEC").get_fastest_lap()

# Get telemetry (get_lap needs an int; LapNumber is a float column)
ver_tel = session.get_driver("VER").get_lap(
    int(ver_fastest["LapNumber"].iloc[0])
).telemetry
lec_tel = session.get_driver("LEC").get_lap(
    int(lec_fastest["LapNumber"].iloc[0])
).telemetry

# Plot speed comparison
import matplotlib.pyplot as plt

plt.figure(figsize=(14, 6))
plt.plot(ver_tel["Distance"], ver_tel["Speed"], label="VER", linewidth=2)
plt.plot(lec_tel["Distance"], lec_tel["Speed"], label="LEC", linewidth=2)
plt.xlabel("Distance (m)")
plt.ylabel("Speed (km/h)")
plt.title("Speed Comparison - Fastest Laps")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### How do I find overtakes?

Detect position changes between consecutive laps:

```python
import tif1
import pandas as pd

session = tif1.get_session(2025, "Italian Grand Prix", "Race")
laps = session.laps

# Sort by driver and lap number
laps_sorted = laps.sort_values(["Driver", "LapNumber"])

# Calculate position change
laps_sorted["PositionChange"] = laps_sorted.groupby("Driver")["Position"].diff()

# Find overtakes (position improved)
overtakes = laps_sorted[laps_sorted["PositionChange"] < 0]

# Display overtakes
for _, overtake in overtakes.iterrows():
    print(f"Lap {int(overtake['LapNumber'])}: {overtake['Driver']} "
          f"gained {abs(int(overtake['PositionChange']))} position(s)")
```

### How do I calculate race pace?

Race pace excludes outliers and pit laps:

```python
import tif1

session = tif1.get_session(2025, "British Grand Prix", "Race")
laps = session.laps

def calculate_race_pace(laps, driver):
    driver_laps = laps[laps["Driver"] == driver].copy()

    # Remove outliers
    driver_laps = driver_laps[
        (driver_laps["PitInTime"].isna()) &
        (driver_laps["LapNumber"] > 1) &
        (~driver_laps["Deleted"])
    ]

    # Remove laps > 107% of fastest (LapTimeSeconds is a float column)
    fastest = driver_laps["LapTimeSeconds"].min()
    driver_laps = driver_laps[driver_laps["LapTimeSeconds"] < fastest * 1.07]

    return driver_laps["LapTimeSeconds"].mean()

# Compare top 3
for driver in ["VER", "HAM", "LEC"]:
    pace = calculate_race_pace(laps, driver)
    print(f"{driver}: {pace:.3f}s average race pace")
```

### How do I work with sprint races?

Sprint races are accessed like regular sessions:

```python
import tif1

# Load sprint race (use a sprint weekend; get_sessions(year, gp) lists the sessions)
session = tif1.get_session(2025, "Chinese Grand Prix", "Sprint")
laps = session.laps

# Sprint races are shorter
print(f"Total laps: {int(laps['LapNumber'].max())}")
final_lap = laps[laps["LapNumber"] == laps["LapNumber"].max()]
print(f"Sprint winner: {final_lap[final_lap['Position'] == 1]['Driver'].iloc[0]}")

# Sprint qualifying
sprint_quali = tif1.get_session(2025, "Chinese Grand Prix", "Sprint Qualifying")
```

### How do I handle missing data?

Missing lap times are `NaT` (pandas) or `null` (polars). Missing telemetry gives an empty DataFrame, not an exception. A driver code that is not in the session raises `DriverNotFoundError`, a subclass of `DataNotFoundError` and of `ValueError` (the fastf1 exception):

```python
import tif1

session = tif1.get_session(2025, "Monaco Grand Prix", "Race")
laps = session.laps

# Check for missing lap times
missing_times = laps[laps["LapTime"].isna()]
print(f"Missing lap times: {len(missing_times)}")

# Check for missing telemetry
for driver in ["VER", "HAM"]:
    try:
        tel = session.get_driver(driver).get_fastest_lap_tel()
    except tif1.DataNotFoundError:
        print(f"{driver}: not in this session")
        continue
    if tel.empty:
        print(f"{driver}: Telemetry not available")
    else:
        print(f"{driver}: Telemetry available ({len(tel)} samples)")
```

### How do I analyze sector times?

Sector analysis shows where time is gained or lost:

```python
import tif1

session = tif1.get_session(2025, "Belgian Grand Prix", "Qualifying")

# Get fastest laps
fastest_laps = session.get_fastest_laps(by_driver=True)

# Find fastest sector times overall
fastest_s1 = fastest_laps["Sector1Time"].min()
fastest_s2 = fastest_laps["Sector2Time"].min()
fastest_s3 = fastest_laps["Sector3Time"].min()

# Calculate deltas for each driver
fastest_laps["S1_Delta"] = fastest_laps["Sector1Time"] - fastest_s1
fastest_laps["S2_Delta"] = fastest_laps["Sector2Time"] - fastest_s2
fastest_laps["S3_Delta"] = fastest_laps["Sector3Time"] - fastest_s3

# Display top 5
print(fastest_laps[["Driver", "S1_Delta", "S2_Delta", "S3_Delta"]].head())

# Find who was fastest in each sector
print(f"Fastest S1: {fastest_laps.loc[fastest_laps['Sector1Time'].idxmin(), 'Driver']}")
print(f"Fastest S2: {fastest_laps.loc[fastest_laps['Sector2Time'].idxmin(), 'Driver']}")
print(f"Fastest S3: {fastest_laps.loc[fastest_laps['Sector3Time'].idxmin(), 'Driver']}")
```

### How do I use tif1 with Streamlit?

tif1 works with Streamlit for interactive dashboards. Install Streamlit first with `pip install streamlit`, then start the script with `streamlit run app.py`:

```python
import streamlit as st
import tif1
import matplotlib.pyplot as plt

st.title("F1 Data Explorer")

# User inputs
year = st.selectbox("Year", range(2018, 2026))
events = tif1.get_events(year)
event = st.selectbox("Event", events["EventName"].tolist())
session_type = st.selectbox("Session", ["Race", "Qualifying", "Practice 1"])

# Load data
if st.button("Load Data"):
    with st.spinner("Loading..."):
        session = tif1.get_session(year, event, session_type)
        laps = session.laps

        st.success(f"Loaded {len(laps)} laps")

        # Display fastest laps
        fastest = session.get_fastest_laps(by_driver=True)
        st.dataframe(fastest[["Driver", "Team", "LapTime"]].head(10))

        # Plot lap time distribution (LapTimeSeconds is a float column)
        fig, ax = plt.subplots()
        ax.hist(laps["LapTimeSeconds"], bins=50)
        ax.set_xlabel("Lap Time (s)")
        ax.set_ylabel("Frequency")
        st.pyplot(fig)
```

### How do I batch process multiple sessions?

Process multiple sessions efficiently:

```python
import tif1
import pandas as pd

def analyze_season(year):
    # Skip pre-season testing: those rounds have no Race session
    events = tif1.get_event_schedule(year, include_testing=False)
    results = []

    for _, event in events.iterrows():
        try:
            session = tif1.get_session(year, event["EventName"], "Race")
            laps = session.laps

            # Get winner
            final_lap = laps[laps["LapNumber"] == laps["LapNumber"].max()]
            winner = final_lap.sort_values("Position").iloc[0]

            results.append({
                "Event": event["EventName"],
                "Winner": winner["Driver"],
                "Team": winner["Team"],
                "FastestLap": laps["LapTime"].min()
            })
        except tif1.DataNotFoundError:
            print(f"Skipping {event['EventName']} - data not available")

    return pd.DataFrame(results)

# Analyze 2024 season
season_results = analyze_season(2024)
print(season_results)
```

### How do I create custom visualizations?

tif1 provides plotting utilities, and custom visualizations are also possible:

```python
import tif1
import matplotlib.pyplot as plt
import seaborn as sns

session = tif1.get_session(2025, "Monaco Grand Prix", "Qualifying")
laps = session.laps

# Custom heatmap of best lap times by driver and qualifying segment
# LapTimeSeconds is a float column; QualifyingSession holds Q1, Q2 or Q3
pivot = laps.pivot_table(
    values="LapTimeSeconds",
    index="Driver",
    columns="QualifyingSession",
    aggfunc="min",
    observed=True,
)

plt.figure(figsize=(10, 12))
sns.heatmap(pivot, annot=True, fmt=".2f", cmap="RdYlGn_r")
plt.title("Qualifying Lap Times Heatmap")
plt.tight_layout()
plt.show()
```
