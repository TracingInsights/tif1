`tif1` can be configured using environment variables or a `.tif1rc` configuration file. Environment variables take precedence over file-based configuration.

## Core Configuration

### TIF1_CACHE_DIR

Location for the SQLite cache database.

```bash
export TIF1_CACHE_DIR="/path/to/cache"
```

<Info>
  Default: Windows `%LOCALAPPDATA%/Temp/tif1`; macOS `~/Library/Caches/tif1`; Linux/other POSIX `~/.cache/tif1` when `~/.cache` exists, otherwise `~/.tif1`.
</Info>

### TIF1_CACHE_ENABLED

Enable or disable caching globally.

```bash
export TIF1_CACHE_ENABLED=false
```

<Info>
  Default: `true`
</Info>

### TIF1_LIB

Default DataFrame lib to use.

```bash
export TIF1_LIB=polars
```

<Info>
  Default: `pandas`

  Options: `pandas`, `polars`
</Info>

## Network Configuration

### TIF1_CDNS

Configure multiple CDN sources for data fetching with automatic fallback.

```bash
export TIF1_CDNS='["https://cdn.staticdelivr.com/gh/TracingInsights", "https://cdn.jsdelivr.net/gh/TracingInsights", "https://huggingface.co/buckets/tracinginsights"]'
```

<Info>
  Default: StaticDelivr (primary), jsDelivr (fallback), Hugging Face buckets (last resort)

  The system tries CDNs in order and automatically falls back on failures.
</Info>

### TIF1_CDN_USE_MINIFICATION

Enable JSON minification for reduced file sizes.

```bash
export TIF1_CDN_USE_MINIFICATION=true
```

<Info>
  Default: `false`

  When enabled, tif1 requests `.min.json` files which are 20-40% smaller.
</Info>

### TIF1_CDN_BASE_URL

Legacy single CDN configuration (deprecated: use `TIF1_CDNS` instead).

```bash
export TIF1_CDN_BASE_URL="https://cdn.jsdelivr.net/gh/TracingInsights"
```

<Warning>
  Change this variable only for a privately hosted data mirror. Never use `raw.githubusercontent.com` because of rate limits.

  Use `TIF1_CDNS` for multi-CDN support with automatic fallback.
</Warning>

### TIF1_REQUEST_TIMEOUT

Timeout for HTTP requests in seconds.

```bash
export TIF1_REQUEST_TIMEOUT=30
```

<Info>
  Default: `10` seconds
</Info>

### TIF1_MAX_RETRIES

Maximum number of retries for failed requests.

```bash
export TIF1_MAX_RETRIES=5
```

<Info>
  Default: `3`
</Info>

### TIF1_RETRY_BACKOFF

Backoff multiplier for exponential retry delays.

```bash
export TIF1_RETRY_BACKOFF=2.0
```

<Info>
  Default: `1.5`

  Formula: `delay = base_delay * (backoff ^ attempt)`
</Info>

## Circuit Breaker

### TIF1_CIRCUIT_BREAKER_THRESHOLD

Number of consecutive failures before opening the circuit.

```bash
export TIF1_CIRCUIT_BREAKER_THRESHOLD=10
```

<Info>
  Default: `5`
</Info>

### TIF1_CIRCUIT_BREAKER_TIMEOUT

Time in seconds before tif1 tries to close an open circuit.

```bash
export TIF1_CIRCUIT_BREAKER_TIMEOUT=120
```

<Info>
  Default: `60` seconds
</Info>

## Logging

### TIF1_LOG_LEVEL

Set the logging verbosity.

```bash
export TIF1_LOG_LEVEL=DEBUG
```

<Info>
  Default: `INFO`

  Options: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`
</Info>

### TIF1_LOG_FILE

Write logs to a file instead of stdout.

```bash
export TIF1_LOG_FILE="/var/log/tif1.log"
```

<Info>
  Default: None (logs to stdout)
</Info>

## Performance Tuning

### TIF1_ASYNC_WORKERS

Number of concurrent workers for async operations.

```bash
export TIF1_ASYNC_WORKERS=20
```

<Info>
  Default: `10`

  Higher values give more parallelism and more memory usage.
</Info>

### TIF1_MEMORY_CACHE_SIZE

Size of the in-memory LRU cache (number of items).

```bash
export TIF1_MEMORY_CACHE_SIZE=200
```

<Info>
  Default: `100`
</Info>

### TIF1_HTTP2_ENABLED

Enable HTTP/2 for network requests.

```bash
export TIF1_HTTP2_ENABLED=true
```

<Info>
  Default: `true`

  Disable this option only when connection problems occur.
</Info>

## Data Processing

### TIF1_USE_CATEGORICAL

Convert string columns to categorical types for memory savings.

```bash
export TIF1_USE_CATEGORICAL=true
```

<Info>
  Default: `true`

  This option can reduce memory usage by 30-50%.
</Info>

### TIF1_TELEMETRY_FREQUENCY

Telemetry sampling frequency in Hz.

```bash
export TIF1_TELEMETRY_FREQUENCY=4
```

<Info>
  Default: `4` Hz

  Higher values give more data points and larger files.
</Info>

## Configuration File

Instead of environment variables, create a `.tif1rc` file in the home directory or the project root.

### Example .tif1rc

```ini
[cache]
enabled = true
directory = <platform-specific default>
memory_size = 100

[network]
cdns = ["https://cdn.staticdelivr.com/gh/TracingInsights", "https://cdn.jsdelivr.net/gh/TracingInsights", "https://huggingface.co/buckets/tracinginsights"]
cdn_use_minification = false
request_timeout = 10
max_retries = 3
retry_backoff = 1.5
http2_enabled = true

[circuit_breaker]
threshold = 5
timeout = 60

[lib]
default = pandas
use_categorical = true

[logging]
level = INFO
file =

[performance]
async_workers = 10
telemetry_frequency = 4
```

## Programmatic Configuration

Configure tif1 directly in code as an alternative.

```python
import tif1

# Get the config singleton
config = tif1.get_config()

# Update settings
config.cache_enabled = False
config.lib = "polars"
config.log_level = "DEBUG"

# Configure multiple CDNs
config.cdns = [
    "https://cdn.staticdelivr.com/gh/TracingInsights",
    "https://cdn.jsdelivr.net/gh/TracingInsights",
    "https://huggingface.co/buckets/tracinginsights"
]
config.cdn_use_minification = True

# Or use the Config class directly
from tif1 import Config

Config.CACHE_DIR = "/custom/cache/path"
Config.MAX_RETRIES = 5
```

## Priority Order

Configuration is resolved in this order (highest to lowest priority):

1. Programmatic configuration in code
2. Environment variables
3. `.tif1rc` in current directory
4. `.tif1rc` in home directory
5. Default values

## Validation

Invalid configuration values raise a `ConfigError` at startup.

```python
import tif1

try:
    config = tif1.get_config()
except tif1.ConfigError as e:
    print(f"Configuration error: {e}")
```
