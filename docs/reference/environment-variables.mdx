`tif1` can be configured using environment variables or a `.tif1rc` configuration file. Environment variables take precedence over file-based configuration. `Config._load_env` in `config.py` reads every variable on this page. The two exceptions are `TIF1_CONFIG_FILE` and `TIF1_TRUST_CWD_CONFIG`, which `Config._load_config` reads to locate the file.

**Value parsing.** Booleans accept `1`, `true`, `yes`, `on` and `0`, `false`, `no`, `off` (case-insensitive). Lists are comma-separated. An unparseable value logs a warning and leaves the previous value in place.

## Core Configuration

### TIF1_CACHE_DIR

Location for the SQLite cache database.

```bash
export TIF1_CACHE_DIR="/path/to/cache"
```

<Info>
  Type: `str`. Default: Windows `%LOCALAPPDATA%/Temp/tif1`; macOS `~/Library/Caches/tif1`; Linux/other POSIX `~/.cache/tif1` when `~/.cache` exists, otherwise `~/.tif1`.
</Info>

### TIF1_ENABLE_CACHE

Enable or disable caching globally.

```bash
export TIF1_ENABLE_CACHE=false
```

<Info>
  Type: `bool`. Default: `true`
</Info>

### TIF1_OFFLINE_MODE

Serve payloads from the cache only. A cache miss raises `NetworkError` instead of contacting a CDN.

```bash
export TIF1_OFFLINE_MODE=true
```

<Info>
  Type: `bool`. Default: `false`
</Info>

### TIF1_CI_MODE

Bypass the payload cache for reads and writes, so every fetch hits the CDN.

```bash
export TIF1_CI_MODE=true
```

<Info>
  Type: `bool`. Default: `false`
</Info>

### TIF1_LIB

Default DataFrame lib to use.

```bash
export TIF1_LIB=polars
```

<Info>
  Type: `str`. Default: `pandas`

  Options: `pandas`, `polars`
</Info>

### TIF1_POLARS_LAP_CATEGORICAL

Use categorical dtypes for string columns in polars lap frames.

```bash
export TIF1_POLARS_LAP_CATEGORICAL=true
```

<Info>
  Type: `bool`. Default: `false`
</Info>

### TIF1_LOG_LEVEL

Set the logging verbosity.

```bash
export TIF1_LOG_LEVEL=DEBUG
```

<Info>
  Type: `str`. Default: `WARNING`

  Options: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`
</Info>

## Network Configuration

### TIF1_CDNS

Configure the CDN sources for data fetching with automatic fallback. The value is a comma-separated list, not JSON. Only `https://` URLs are accepted; `raw.githubusercontent.com` is skipped.

```bash
export TIF1_CDNS="https://cdn.jsdelivr.net/gh/TracingInsights,https://huggingface.co/buckets/tracinginsights,https://cdn.staticdelivr.com/gh/TracingInsights"
```

<Info>
  Type: `list[str]`. Default: jsDelivr (primary), Hugging Face buckets (fallback), StaticDelivr (last resort)

  The system tries CDNs in order and automatically falls back on failures.
</Info>

<Note>
  The `cdn_use_minification` config key has no environment variable. Set it in `.tif1rc` or with `config.set("cdn_use_minification", True)`.
</Note>

### TIF1_TIMEOUT

## HTTP Session

### TIF1_HTTP_MULTIPLEXED

Enable HTTP/2 multiplexing for multiple requests over one connection.

```bash
export TIF1_HTTP_MULTIPLEXED=false
```

<Info>
  Type: `bool`. Default: `true`

  Disable this option only when a proxy or CDN causes connection problems.
</Info>

### TIF1_HTTP_DISABLE_HTTP3

Disable HTTP/3 (QUIC) support. HTTP/2 over TCP is the default. Set it to `false` to negotiate HTTP/3 again.

```bash
export TIF1_HTTP_DISABLE_HTTP3=false
```

<Info>
  Type: `bool`. Default: `true`
</Info>

### TIF1_CDN_PRECONNECT

Warm the shared CDN connection (DNS and TLS) in a background thread while `get_session()` returns. The first payload request of a cold load then rides an open connection. Set to `false` to keep `get_session()` free of network activity.

```bash
export TIF1_CDN_PRECONNECT=false
```

<Info>
  Type: `bool`. Default: `true`. Skipped automatically in offline and CI mode.
</Info>

### TIF1_HTTP2_MAX_CONNECTIONS

Maximum HTTP/2 connections per host.

```bash
export TIF1_HTTP2_MAX_CONNECTIONS=20
```

<Info>
  Type: `int`. Default: `10`
</Info>

### TIF1_HTTP2_MAX_POOL_SIZE

HTTP/2 connection pool size.

```bash
export TIF1_HTTP2_MAX_POOL_SIZE=40
```

<Info>
  Type: `int`. Default: `20`
</Info>

### TIF1_POOL_CONNECTIONS

Number of connection pools. The library clamps explicit values to a minimum of `10`.

```bash
export TIF1_POOL_CONNECTIONS=512
```

<Info>
  Type: `int`. Default: unset; the library computes `max(256, max_workers, max_concurrent_requests, telemetry_prefetch_max_concurrent_requests)`.
</Info>

### TIF1_POOL_MAXSIZE

Maximum connections per pool. The library clamps explicit values to a minimum of `512`.

```bash
export TIF1_POOL_MAXSIZE=2048
```

<Info>
  Type: `int`. Default: unset; the library computes `max(512, pool_connections * 4)`.
</Info>

### TIF1_KEEPALIVE_TIMEOUT

Keep-alive timeout in seconds.


<Info>
  Type: `int`. Default: `120`

## Configuration File Control

### TIF1_CONFIG_FILE

Explicit path to a `.tif1rc` JSON file. It is checked first in the lookup order.

```bash
export TIF1_CONFIG_FILE="/path/to/config.json"
```

<Info>
  Type: `str`. Default: unset
</Info>

### TIF1_TRUST_CWD_CONFIG

Allow tif1 to read `.tif1rc` from the current working directory.

```bash
export TIF1_TRUST_CWD_CONFIG=true
```

<Info>
  Type: `bool`. Default: `false`
</Info>

<Warning>
  Set `TIF1_TRUST_CWD_CONFIG=true` only in trusted directories. A `.tif1rc` in an untrusted checkout could redirect the CDN list or the cache directory.
</Warning>

## Configuration File

Instead of environment variables, create a `.tif1rc` file. The file is a JSON object keyed by configuration key. A configuration key is the environment variable name without the `TIF1_` prefix, in lowercase. tif1 loads the first file found in this order:

1. The path in `TIF1_CONFIG_FILE`, when set
2. `./.tif1rc` in the current working directory, only when `TIF1_TRUST_CWD_CONFIG=true`
3. `~/.tif1rc` in the home directory

A file whose root is not a JSON object is skipped with a warning.

### Example .tif1rc

```json
{
  "enable_cache": true,
  "cache_dir": "/path/to/cache",
  "memory_cache_max_items": 1024,
  "memory_telemetry_cache_max_items": 2048,
  "cdns": [
    "https://cdn.jsdelivr.net/gh/TracingInsights",
    "https://huggingface.co/buckets/tracinginsights",
    "https://cdn.staticdelivr.com/gh/TracingInsights"
  ],
  "cdn_use_minification": false,
  "timeout": 30,
  "max_retries": 3,
  "retry_backoff_factor": 2.0,
  "http_multiplexed": true,
  "circuit_breaker_threshold": 5,
  "circuit_breaker_timeout": 60,
  "lib": "pandas",
  "polars_lap_categorical": false,
  "log_level": "WARNING",
  "max_workers": 20,
  "max_concurrent_requests": 22
}
```

## Programmatic Configuration

Configure tif1 directly in code as an alternative. The `Config` object exposes `get(key, default=None)`, `set(key, value)`, and `save(path=None)`; there is no attribute API, and `tif1` does not export the `Config` class.

```python
import tif1

# Get the config singleton
config = tif1.get_config()

# Update settings
config.set("enable_cache", False)
config.set("lib", "polars")
config.set("log_level", "DEBUG")

# Configure multiple CDNs
config.set("cdns", [
    "https://cdn.jsdelivr.net/gh/TracingInsights",
    "https://huggingface.co/buckets/tracinginsights",
    "https://cdn.staticdelivr.com/gh/TracingInsights",
])
config.set("cdn_use_minification", True)

# Read settings back
print(config.get("cache_dir"))
print(config.get("max_retries"))

# Persist the whole configuration to ~/.tif1rc
config.save()
```

## Priority Order

Configuration is resolved in this order (highest to lowest priority):

1. Programmatic `config.set()` calls
2. Environment variables
3. The first `.tif1rc` found: `TIF1_CONFIG_FILE`, then `./.tif1rc` (only with `TIF1_TRUST_CWD_CONFIG=true`), then `~/.tif1rc`
4. Default values

## Validation

tif1 raises no configuration exception at startup. A value that fails type conversion logs a warning and keeps the previous value. Range checks run on read: `config.get()` logs a warning and returns the supplied default for an invalid value.

```python
import tif1

config = tif1.get_config()
config.set("timeout", -1)
print(config.get("timeout", 30))  # 30, with a warning in the log
```
