The `tif1` CLI provides quick access to F1 data without writing Python code. It is a thin wrapper around the Python API: each command loads data through `tif1.get_events()`, `tif1.get_sessions()`, or `tif1.get_session()` and prints a table.

## Installation

The CLI is included with tif1. Verify the installation:

```bash
tif1 version
```

## Usage

```bash
tif1 [OPTIONS] COMMAND [ARGS]...
```

The CLI has no global options other than the standard ones below. Behaviour such as the DataFrame backend or caching is controlled through [environment variables](#environment-variables) or a `.tif1rc` file.

| Option | Description |
| :--- | :--- |
| `--help` | Show help for the CLI or for one command and exit |
| `--install-completion` | Install shell completion for the current shell |
| `--show-completion` | Print the completion script instead of installing it |

Every command accepts `--help`, for example `tif1 fastest --help`.

### cache-info

Show where the cache lives and how large it is.

```bash
tif1 cache-info
```

```text
Cache location: /home/user/.cache/tif1
Cache files: 3
Total size: 184.52 MB
```

The size counts the SQLite database and its WAL/SHM files. If no `cache.sqlite*` file exists yet, it counts every file in the cache directory. Set `TIF1_CACHE_DIR` to move the cache.

### cache-clear

Delete all cached data. The command asks for confirmation unless `--yes` is given.

```bash
tif1 cache-clear [--yes]
```

**Options:**

| Option | Description |
| :--- | :--- |
| `--yes`, `-y` | Skip the confirmation prompt (for scripts) |

### version

Print the installed tif1 version.

```bash
tif1 version
```

```text
tif1 version 0.8.0
```

### debug

Load a session with debug logging enabled and print a short summary. Use it to see which CDN sources and cache tiers a load touches.

```bash
tif1 debug YEAR EVENT SESSION
```

```text
Session loaded successfully!
Drivers: 20
Laps: 1247
```

## Environment Variables

The CLI reads the same configuration as the Python API. The most useful variables are:

```bash
# Use the polars backend for the fastest-lap table
export TIF1_LIB=polars
tif1 fastest 2025 "Monaco Grand Prix" Race

# Disable the on-disk cache
export TIF1_ENABLE_CACHE=false
tif1 drivers 2025 "Monaco Grand Prix" Race

# Verbose logging for every command
export TIF1_LOG_LEVEL=DEBUG
tif1 events 2025

# Serve only from the cache, never from the network
export TIF1_OFFLINE_MODE=true
tif1 fastest 2025 "Monaco Grand Prix" Race
```

See the [environment variables reference](/reference/environment-variables) for the full list.

## Shell Completion

Typer generates completion scripts for bash, zsh, fish, and PowerShell.

```bash
# Install completion for the current shell, then restart the shell
tif1 --install-completion

# Or print the script to inspect it
tif1 --show-completion
```

## Piping and Scripting

Commands print formatted tables, not machine-readable output. For scripting, grep the table or use the Python API directly.

```bash
# Check that a session exists before running a longer job
if tif1 sessions 2025 "Monaco Grand Prix" | grep -q "Race"; then
  tif1 fastest 2025 "Monaco Grand Prix" Race
fi

# Machine-readable data: use Python
python -c "import tif1; print(tif1.get_session(2025, 'Monaco', 'Race').laps.to_csv())" > laps.csv
```

## Exit Codes

| Exit Code | Meaning |
| :--- | :--- |
| `0` | Success |
| `1` | A `tif1` error (for example data not found, network failure) or any other exception; the traceback is printed |
| `2` | Usage error: missing or invalid arguments |

```bash
tif1 fastest 2025 "Not A Grand Prix" Race
echo $?  # 1
```
